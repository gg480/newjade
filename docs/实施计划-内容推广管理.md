# 实施计划：内容推广管理模块

> 版本：v1.0 | 日期：2026-06-19
> 依据：PRD v0.3 + 假设评审报告 + API对接规范 + OpenClaw配合指令
> 工作流：planning-and-task-breakdown skill

---

## 概述

在 jade ERP 中新增"内容推广管理"模块，实现选题管理、文案审核、推广追踪、反馈分析、AI配置 5 大功能。采用 OpenClaw+ERP 两端协作架构，ERP 作为用户唯一交互入口，OpenClaw 通过定时轮询 ERP API 自动执行选题采集/文案生成等任务。

## 架构决策

| 决策 | 理由 |
|------|------|
| **垂直切片**：每个任务完成一条完整功能路径（schema+API+UI） | 遵循 planning-and-task-breakdown skill，每片可独立验证 |
| **文件所有权隔离**：后端任务只改后端文件，前端任务只改前端文件 | 遵循 file-ownership.md 跨所有权规则 |
| **串行编排**：基础设施→后端API→前端UI | 遵循 file-ownership.md 串行编排顺序 |
| **双Token认证**：用户会话Token + OpenClaw API Key | 解决7天Token过期问题，OpenClaw长期运行 |
| **Phase 1 只做 P0**：14个MVP功能 | P1/P2 留待 OpenClaw 集成阶段 |
| **修正PRD虚假假设**：删除不存在的仓库引用 | 基于假设评审报告 |
