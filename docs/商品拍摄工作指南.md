# 商品拍摄工作指南

> 适用环境：三盏柔光灯 + 支架（手机/相机）
> 更新日期：2026-06-15

---

## 一、设备与基础设置

### 1.1 灯光布局（标准三灯位）

```
         ┌─────────────┐
         │   柔光灯1    │  ← 主灯（左前45°，亮度最高）
         │  (左前侧光)  │
         └─────────────┘

              │
         ┌────┴────┐
         │  商品区  │
         └────┬────┘
              │
    ┌─────────┴──────────┐
    │     柔光灯2         │  ← 辅灯（右后侧，亮度为主灯1/2）
    │   (右后侧轮廓光)    │
    └────────────────────┘

    ┌────────────────────┐
    │     柔光灯3         │  ← 顶灯（正上方俯射，亮度为主灯1/3）
    │   (顶光消除阴影)    │
    └────────────────────┘
```

### 1.2 相机设置（手机/相机通用）

| 参数 | 设置 |
|------|------|
| 白平衡 | 手动设定 5200K（日光色温恒定） |
| ISO | 固定 100-200（最低可用值） |
| 光圈 | f/8 - f/11（保证景深） |
| 快门 | 1/60s 以上（防抖） |
| 焦距 | 1x 主摄（避免数码变焦） |
| 闪光灯 | **关闭**（只用柔光灯） |

### 1.3 背景选择

| 材质类别 | 推荐背景 | 说明 |
|----------|---------|------|
| 贵金属 | 黑色亚光 / 深灰绒布 | 金属反光强，深色背景突出质感 |
| 玉（翡翠/和田玉） | 白色亚光 / 浅灰 | 玉石透光性强，浅色背景显水头 |
| 水晶 | 白色 / 浅灰 | 水晶通透，浅色背景显净度 |
| 文玩 | 黑色亚光 / 木纹 | 文玩色深，深色背景显包浆 |
| 珍珠 | 白色 / 浅粉 | 珍珠光泽柔和，浅色背景显晕彩 |
| 其他 | 白色亚光 | 通用安全色 |

## 二、拍摄方案总览（共36种拍法）

按材质光学特性分为四大类，每类下按器型细分：

| 大类 | 分类逻辑 | 拍法数量 | 涵盖材质 |
|:----:|----------|:--------:|----------|
| A | 反光类（贵金属） | 8种 | 黄金、K金、玫瑰金、K白金、银、铂金 |
| B | 透光/半透光类（玉+水晶） | 14种 | 翡翠、和田玉、碧玺、水晶全系列 |
| C | 吸光/哑光类（文玩+其他） | 8种 | 朱砂、蜜蜡、琥珀、珍珠、锆石等 |
| D | 组合材质类 | 6种 | 金镶玉、镶嵌类、多材质手串等 |

---

## 三、A类：反光材质拍摄（贵金属）

### 核心难点
金属表面高反光，容易拍出环境倒影和过曝高光点。

### 灯光调整
- **主灯**：左前45°，加柔光箱/硫酸纸，距离商品 40-50cm
- **辅灯**：右后侧60°，亮度减半，打出轮廓光
- **顶灯**：正上方，亮度最低，仅补顶部暗区
- **关键技巧**：在镜头前方用黑卡纸挖洞遮挡，只留镜头孔，消除相机倒影

### A1-A8 按器型细分

| 编号 | 器型 | 拍摄角度 | 构图要点 | 特殊处理 |
|:----:|:----:|:---------|----------|----------|
| **A1** | 手镯 | 45°俯拍 + 正侧90° | 拍出圈口圆润感，展示内壁刻字 | 用支架悬空，避免桌面倒影 |
| **A2** | 戒指 | 正俯拍 + 侧45° | 突出戒面/镶嵌，展示指圈内侧刻印 | 用戒指座固定，微距模式 |
| **A3** | 吊坠/挂件 | 正俯拍 + 侧30° | 展示链子+坠子整体比例 | 悬挂拍摄（用鱼线挂起） |
| **A4** | 耳饰 | 正俯拍（一对） | 左右对称摆放，展示背面耳针 | 用耳饰架固定 |
| **A5** | 手链/手串 | 平铺展开 + 自然弧度 | 展示扣头、延长链 | 用白蜡固定位置 |
| **A6** | 项链 | 弧形展开 + 局部特写 | 展示链身纹理、搭扣细节 | 用模特颈架或平铺 |
| **A7** | 脚链 | 平铺展开 | 展示长度和扣头 | 同手链拍法 |
| **A8** | 摆件 | 45°环绕3张 | 展示立体感和金属光泽 | 转台拍摄 |

## 四、B类：透光/半透光材质拍摄（玉 + 水晶）

### B1 玉类（翡翠、和田玉）

#### 核心难点
玉石需要表现"种水"（通透度）和颜色。透光拍摄是关键。

#### 灯光调整
- **主灯**：左前45°，柔光，距离 30-40cm
- **辅灯**：右后侧，亮度为主灯 2/3
- **顶灯**：商品正上方，亮度为主灯 1/2
- **关键技巧**：在商品后方或侧后方加一盏小LED手电筒，从背面打透射光，展现玉石内部结构

| 编号 | 器型 | 拍摄角度 | 构图要点 | 特殊处理 |
|:----:|:----:|:---------|----------|----------|
| **B1** | 手镯 | 45°俯拍 + 透光拍 | 展示镯身颜色均匀度 | 背面打透射光看内部纹理 |
| **B2** | 挂件/吊坠 | 正俯拍 + 背面透光 | 展示雕刻线条和题材 | 背面强透光拍"水头" |
| **B3** | 手串 | 平铺 + 局部特写 | 展示每颗珠子的颜色过渡 | 逐颗旋转检查裂痕 |
| **B4** | 摆件 | 45°环绕4张 | 展示雕刻立体感 | 侧逆光强调雕刻轮廓 |

### B2 水晶类（22种材质）

#### 核心难点
水晶透明度高，容易拍成"玻璃"。需要表现内部包裹体、冰裂、发丝等特征。

#### 灯光调整
- **主灯**：左前45°，柔光，距离 30cm
- **辅灯**：右后侧，亮度为主灯 1/2
- **顶灯**：关闭或最低亮度
- **关键技巧**：黑色背景 + 侧逆光，让水晶内部结构在暗背景下发光

| 编号 | 水晶类型 | 拍法说明 | 代表材质 |
|:----:|:---------|:---------|:---------|
| **B5** | 全净体/高透 | 黑色背景 + 侧逆光，突出通透感 | 白水晶、紫水晶、黄水晶 |
| **B6** | 发晶/包裹体 | 强侧逆光，旋转找角度让内部发丝反光 | 金发晶、钛晶、绿幽灵、彩幽灵 |
| **B7** | 半透明/微透 | 白色背景 + 正面光，展示颜色 | 粉晶、碧玺、海蓝宝 |
| **B8** | 特殊光学效应 | 单光源旋转，捕捉猫眼/星光/彩虹光 | 猫眼碧玺、星光粉晶、彩虹水晶 |
| **B9** | 多色/共生 | 多角度拍摄，展示颜色过渡带 | 碧玺（西瓜碧玺）、红绿宝石共生 |
| **B10** | 不透明宝石 | 同玉类拍法，正面光为主 | 青金石、黑曜石、玛瑙 |
| **B11** | 手串类 | 平铺 + 局部特写，展示珠子整体一致性 | 所有水晶材质的手串 |
| **B12** | 吊坠 | 悬挂拍摄，展示坠子整体 | 所有水晶材质的吊坠 |
| **B13** | 耳饰 | 成对俯拍，展示对称性 | 所有水晶材质的耳饰 |
| **B14** | 摆件/原石 | 45°环绕，展示晶体形态 | 水晶簇、紫晶洞 |

## 五、C类：吸光/哑光材质拍摄（文玩 + 其他）

### C1 文玩类（朱砂、蜜蜡、琥珀）

#### 核心难点
文玩质感厚重，需要表现包浆和油润感。

#### 灯光调整
- **主灯**：左前45°，柔光，距离 30cm
- **辅灯**：右前侧，亮度为主灯 1/2
- **顶灯**：关闭
- **关键技巧**：用偏光片消除表面反光，拍出哑光质感

| 编号 | 材质 | 拍法说明 | 特殊处理 |
|:----:|:----:|:---------|:---------|
| **C1** | 朱砂 | 正面光为主，展示红色饱和度 | 避免过曝，红色容易溢出 |
| **C2** | 蜜蜡 | 强透射光展示内部流淌纹 | 背后打光看天然纹理 |
| **C3** | 琥珀 | 透射光展示内部包裹体 | 黑色背景 + 强背光看昆虫/植物 |
| **C4** | 文玩手串 | 自然光感，展示油润包浆 | 擦净表面油污再拍 |

### C2 其他类（珍珠、锆石、斑彩螺）

| 编号 | 材质 | 拍法说明 | 特殊处理 |
|:----:|:----:|:---------|:---------|
| **C5** | 珍珠 | 柔光环绕，展示珍珠晕彩 | 白色背景 + 多角度柔光，避免硬阴影 |
| **C6** | 锆石 | 强光展示火彩（色散） | 单光源旋转，捕捉闪光 |
| **C7** | 斑彩螺 | 45°俯拍，展示螺面虹彩 | 自然光最佳，避免强光冲淡颜色 |
| **C8** | 珍珠串/手链 | 平铺展示，突出大小均匀度 | 用针线固定位置 |

## 六、D类：组合材质拍摄（镶嵌类）

### 核心难点
多种材质组合（如金镶玉），需要同时兼顾不同材质的光学特性。

### 通用原则
1. 以主材质为准设定灯光
2. 镶嵌类以金属曝光为准（金属更容易过曝）
3. 分两次拍摄：整体图 + 局部特写

| 编号 | 组合类型 | 拍法说明 | 示例 |
|:----:|:---------|:---------|:-----|
| **D1** | 金镶玉 | 以玉为主曝光，后期提亮金属 | 翡翠镶嵌、和田玉镶嵌 |
| **D2** | 宝石镶嵌 | 以金属曝光为准，宝石补光 | 钻戒、宝石戒指 |
| **D3** | 多材质手串 | 平铺拍摄，展示整体搭配 | 水晶+银饰、翡翠+金珠 |
| **D4** | 珐琅/花丝 | 微距特写，展示工艺细节 | 贵金属+珐琅彩 |
| **D5** | 珍珠+金属 | 柔光为主，避免金属反光过曝 | 珍珠项链+金扣 |
| **D6** | 多材质摆件 | 45°环绕4张，展示整体 | 玉石+木座组合 |

## 七、通用拍摄流程（每件商品的标准步骤）

### 第1步：准备工作（2分钟）
1. 清洁商品表面（擦去指纹、灰尘、油污）
2. 选择对应类别的背景板
3. 按材质类别调整灯光位置（参考上方灯光方案）
4. 手机/相机设为手动模式（白平衡5200K、ISO 100）

### 第2步：拍摄标准照（每件3张）
| 序号 | 角度 | 说明 |
|:----:|:----:|------|
| 第1张 | 正面俯拍 | 商品正上方45°，展示整体 |
| 第2张 | 侧面45° | 展示立体感和厚度 |
| 第3张 | 局部特写 | 展示材质细节/工艺/刻印 |

### 第3步：拍摄特征照（按需，最多3张）
- 玉石：背面透光照（展示水头/内部结构）
- 水晶：侧逆光照（展示内部包裹体/发丝）
- 贵金属：微距刻印（展示钢印/成色标记）
- 组合材质：分材质分别对焦拍2张

### 第4步：检查与上传
1. 检查是否清晰（放大查看细节）
2. 检查曝光是否准确（金属不过曝、玉石不欠曝）
3. 检查背景是否干净（无杂物、无倒影）
4. 上传到系统（通过批量补图功能）

## 八、常见问题处理

| 问题 | 原因 | 解决方法 |
|:----:|:----:|:---------|
| 金属反光过曝 | 灯光太强或角度不对 | 降低主灯亮度，或加硫酸纸柔化 |
| 玉石拍不出水头 | 缺少透射光 | 在商品后方加一个小LED手电筒从背面打光 |
| 水晶拍出来像玻璃 | 背景太亮 | 换黑色背景 + 侧逆光 |
| 商品有阴影 | 灯光不均匀 | 加顶灯补光，或调整辅灯位置 |
| 颜色偏色 | 白平衡不准 | 用灰卡手动校准白平衡 |
| 拍不出珍珠晕彩 | 灯光太硬 | 用大柔光箱，让光线更柔和扩散 |
| 手链/项链不平整 | 摆放不固定 | 用透明鱼线固定，或用白蜡/蓝丁胶辅助定位 |
| 背景有褶皱 | 背景布未铺平 | 用夹子拉平背景布，或用亚克力板压平 |

## 十一、系统操作指引：扫码拍摄功能

> 本功能位于系统**库存管理 → 扫码拍摄**入口。支持两种工作模式：**扫码拍摄**（先扫后拍）和**临时拍照**（先拍后录）。

### 11.1 功能入口

- **位置**: 库存管理页面（Inventory Tab）顶部操作栏，点击"扫码拍摄"按钮
- **依赖**: 浏览器需授予摄像头权限（首次使用浏览器会弹出授权提示）
- **兼容性**: 支持 Chrome/Edge/Firefox 桌面端，推荐使用 Chrome

### 11.2 模式一：扫码拍摄（标准流程）

此模式适用于已入库商品，通过扫码枪定位SKU后拍照上传。

#### 操作步骤

| 步骤 | 操作 | 说明 |
|:----:|:----|:------|
| 1 | 点击"扫码拍摄"按钮 | 打开扫码拍摄面板 |
| 2 | 用扫码枪扫描商品SKU | 系统自动查询商品信息，显示商品名称、材质、器型 |
| 3 | 选择拍摄角度 | 6个角度可选：**正面**、**侧面**、**特写**、**特征1**、**特征2**、**特征3** |
| 4 | 点击"拍照"按钮 | 调用摄像头拍照，生成缩略图预览 |
| 5 | 检查照片质量 | 如不满意可点击删除按钮重新拍摄 |
| 6 | 切换角度继续拍摄 | 每个角度可拍多张，系统自动编号 |
| 7 | 点击"完成拍摄" | 所有照片自动上传并关联到该SKU |

#### 角度选择建议

| 角度 | 适用场景 | 拍摄要点 |
|:----:|:---------|:---------|
| 正面 | 所有商品 | 商品正上方45°，展示整体 |
| 侧面 | 所有商品 | 展示立体感和厚度 |
| 特写 | 所有商品 | 展示材质细节/工艺/刻印 |
| 特征1 | 玉石类 | 背面透光照（展示水头/内部结构） |
| 特征2 | 水晶类 | 侧逆光照（展示内部包裹体/发丝） |
| 特征3 | 贵金属 | 微距刻印（展示钢印/成色标记） |

### 11.3 模式二：临时拍照（先拍后录）

此模式适用于未入库商品或批量拍摄场景，先拍照后关联SKU。

#### 操作步骤

| 步骤 | 操作 | 说明 |
|:----:|:----|:------|
| 1 | 打开扫码拍摄面板 | 保持SKU输入框为空 |
| 2 | 选择拍摄角度 | 同上6个角度 |
| 3 | 点击"拍照" | 照片存入临时目录，文件名格式 `temp_{时间戳}_{角度}_{序号}.jpg` |
| 4 | 重复拍摄 | 可切换角度连续拍摄多张 |
| 5 | 点击"完成拍摄" | 照片上传到服务器临时目录 |
| 6 | 后续关联 | 在入库或编辑商品时，可从临时照片库中选择关联到SKU |

#### 使用场景

- **批量拍摄**: 先集中拍摄所有商品，后续统一录入系统
- **外出拍摄**: 离线拍摄后回到系统上传关联
- **快速记录**: 来不及扫码时先拍照留存

### 11.4 功能说明

| 项目 | 说明 |
|:----:|:------|
| 摄像头切换 | 支持前后摄像头切换（适用于笔记本/手机） |
| 照片预览 | 拍摄后自动生成缩略图，点击可查看大图 |
| 删除重拍 | 每张照片可单独删除重新拍摄 |
| 角度标签 | 照片自动标注角度代码（front/side/closeup/feature1/feature2/feature3） |
| 文件命名 | 扫码模式：`{SKU}_{角度}_{序号}.jpg`；临时模式：`temp_{时间戳}_{角度}_{序号}.jpg` |
| 上传时机 | 点击"完成拍摄"后批量上传，非逐张上传（节省网络开销） |

### 11.5 注意事项

1. **摄像头权限**: 首次使用请允许浏览器访问摄像头，如误拒绝需在浏览器设置中重新授权
2. **光线要求**: 建议在灯光充足的环境下拍摄（参考本指南的灯光布局方案）
3. **扫码枪设置**: 扫码枪需设置为**模拟键盘输入**模式（默认），扫码后自动触发SKU查询
4. **照片管理**: 临时照片在服务器保留7天，逾期自动清理
5. **网络要求**: 拍摄完成后点击"完成拍摄"需保持网络畅通，确保照片上传成功
